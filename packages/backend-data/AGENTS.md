# AWS-AccessBridge — Backend Data (D1/DAO Layer)

Scope: `packages/backend-data/**`. Parent index: `../../AGENTS.md`.

All D1 access via DAOs extending `dao/BaseDAO.ts` (`BaseDAO` — `ctor(database: D1Queryable)`, `withRetry()`, static `findById`/`deleteOlderThan` with SQL-identifier allow-list, instance `findRowById`/`deleteRowsOlderThan` push-downs; `EncryptedDAO` — adds `masterKey` for encrypted rows, e.g. `CredentialsDAO`): `CredentialsDAO`, `AssumableRolesDAO` (+ `AssumableRolesQueries` shared SQL fragments + `AssumableRolesMapper.mapRowsToAssumableMap` pure mapper), `AwsAccountsDAO`, `RoleConfigsDAO`, `UserMetadataDAO`, `UserFavoriteAccountsDAO`, `UserAccessTokenDAO`, `AuditLogDAO`, `CostDataDAO`, `DataCollectionConfigDAO`, `SpendAlertDAO`, `ResourceInventoryDAO`, `CredentialCacheConfigDAO`, `CredentialsCacheDAO` (KV), `BackgroundTaskRunDAO`, `TeamsDAO`, `TeamMembersDAO`, `TeamAccountsDAO`; `IKeyValueDAO` KV contract (`get`/`put`/`delete` all namespace the key — `delete` must too); `crypto/` (`aes-gcm`, `hmac` for AES-GCM credential encryption + internal HMAC signing — `encryptData` deliberately takes no caller-supplied IV, see below); `constants/` (`kv/` namespaces/TTL/value-type, `d1/` session constraints); `utils/` (`D1Utils.executeD1WithRetry` + `assertD1Success`, `D1ErrorClassifier.isD1ErrorRetryable`, `D1SessionUtil` (`D1Queryable`, `createD1SessionEnv`)).

**Credential encryption**: every encrypted field gets its own random 96-bit AES-GCM IV, stored in its own column (`salt`, `salt_secret_access_key`, `salt_session_token`). Never reuse an IV across fields under one key — it leaks the XOR of the plaintexts and enables tag forgery. `encryptData` therefore accepts no IV argument. Rows written before `migrations/0031_distinct_credential_ivs.sql` carry only `salt`; reads fall back to it (`CredentialsDAO.resolveIv`, and the same fallback in `CredentialsCacheDAO`), so old rows keep working and are upgraded on their next write.

The 7 `deleteOrphaned()` implementations write their own inline SQL; `BaseDAO.deleteOrphanedRows` exists but is not used by any of them.

Conventions: DAOs extend `BaseDAO`/`EncryptedDAO` (never redeclare `database`); failed writes throw `DatabaseError` on `!result.success` (`retryable` flag drives `executeD1WithRetry` backoff); batch deletes expose `deleteOlderThanBatch(cutoff, batchSize): Promise<number>` (D1 `DELETE … LIMIT ?`, `meta.changes ?? 0`) for `AbstractPruningTask`; models use dual camelCase/snake_case `Type`/`TypeInternal` pairs from `@aws-access-bridge/shared/model`. Routes must not import DAOs (ESLint-enforced in `apps/api/src/endpoints/**`, type-only imports excepted) — compose `backend-services` domain services instead.
