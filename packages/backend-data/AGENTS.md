# AWS-AccessBridge — Backend Data (D1/DAO Layer)

Scope: `packages/backend-data/**`. Parent index: `../../AGENTS.md`.

All D1 access via DAOs extending `dao/BaseDAO.ts` (`BaseDAO` — `ctor(database: D1Queryable)`, `withRetry()`, static `findById`/`deleteOlderThan` with SQL-identifier allow-list; `EncryptedDAO` — adds `masterKey` for encrypted rows, e.g. `CredentialsDAO`): `CredentialsDAO`, `AssumableRolesDAO`, `AwsAccountsDAO`, `RoleConfigsDAO`, `UserMetadataDAO`, `UserFavoriteAccountsDAO`, `UserAccessTokenDAO`, `AuditLogDAO`, `CostDataDAO`, `DataCollectionConfigDAO`, `SpendAlertDAO`, `ResourceInventoryDAO`, `CredentialCacheConfigDAO`, `CredentialsCacheDAO` (KV), `BackgroundTaskRunDAO`, `TeamsDAO`, `TeamMembersDAO`, `TeamAccountsDAO`; `IKeyValueDAO` KV contract; `crypto/` (`aes-gcm`, `hmac` for AES-GCM credential encryption + internal HMAC signing); `constants/` (`kv/` namespaces/TTL/value-type, `d1/` session constraints); `utils/` (`D1Utils.executeD1WithRetry` + `assertD1Success`, `D1ErrorClassifier.isD1ErrorRetryable`, `D1SessionUtil` (`D1Queryable`, `createD1SessionEnv`), `RepositoryHelper` (`pruneInBatches`, `computeUnixCutoffSeconds`)).

Conventions: DAOs extend `BaseDAO`/`EncryptedDAO` (never redeclare `database`); failed writes throw `DatabaseError` on `!result.success` (`retryable` flag drives `executeD1WithRetry` backoff); batch deletes expose `deleteOlderThanBatch(cutoff, batchSize): Promise<number>` (D1 `DELETE … LIMIT ?`, `meta.changes ?? 0`) for `AbstractPruningTask`; models use dual camelCase/snake_case `Type`/`TypeInternal` pairs from `@aws-access-bridge/shared/model`. Routes must not import DAOs (ESLint-enforced in `apps/api/src/endpoints/**`, type-only imports excepted) — compose `backend-services` domain services instead.
