# AWS-AccessBridge — Backend Services (Business Logic)

Scope: `packages/backend-services/**`. Parent index: `../../AGENTS.md`. Feature details: `../../docs/agents/features/*/AGENTS.md`.

Instance services by domain (constructor-injected narrow `*Env`, instantiated per-request via `*Factory.create(env)` — no IoC container, no singletons): `credential/` (`CredentialService` — chain resolution incl. cache-short-circuit, store/relationship CRUD, STS validate, chain test/walk), `aws/assume-role/` (`AssumeRoleService` — access check → chain → cached-hop reuse → chain walk), `aws/console/` (`ConsoleService` — signin tokens, login/issuer/destination URL builders), `aws/sts/` (`StsService` — assume-role hop, `validateCredentials`; injectable `AwsClientFactory`), `aws/iam/` (`IamService` — role discovery), `aws/ce/` (`CostExplorerService`), `aws/collectors/` (`IAwsResourceCollector` Strategy + `CollectorRegistry` with `createCollectorRegistry(overrides)` test seam: `Ec2/S3/Lambda/Rds/DynamoDbCollector`), `auth/` (`AccessAuthService` — Access JWT/demo/dev; `TokenService` — PAT auth + token CRUD), `account/` (`AccountService` — nicknames, role configs, role discovery), `access/` (`AccessService` — grant/revoke), `user/` (`UserService` — profile, favorites, hidden roles, assumables), `cost/` (`CostService` — summary/account/trends, alerts, collection config), `resource/` (`ResourceService` — search/summary), `team/` (`TeamService`), `maintenance/` (`MaintenanceService` — orphan cleanup, task runs), `audit/` (`AuditService` + `AuditEventBuilder` + `AuditLogObserver` fan-out via `Promise.allSettled`; `AUDIT_ACTIONS` map), `http/` (`IHttpClient` → `FetchHttpClient`/`StubHttpClient`).

Pure static utilities stay static (Otter precedent): `aws/ArnUtil`, `aws/BaseUrlUtil`, `aws/InternalRequestHelper` (instance, holds fetcher+secret), `error/` (`ErrorTranslationUtil`, `ErrorDeserializationUtil`).

Related packages: `shared/` (constants, models, schemas, utils `TimestampUtil`, `UUIDUtil`, `RequestOriginUtil`, `EmailUtil`; `i18n/` with `BackendStrings` + `formatBackendString`, `getBackendStrings`), `backend-errors/` (`BadRequestError`, `UnauthorizedError`, `ForbiddenError`, `MethodNotAllowedError`, `InternalServerError`, `DatabaseError` (+`retryable`), `IServiceError`, message constants), `backend-runtime/` (env `ConfigurationDefaults`, `ConfigurationManager` namespaced getters + `EnvParser`, `Configurations`; abstract worker bases `AbstractEntrypointWorker`, `AbstractDurableObjectWorker`; DO naming constants; checked-in `env.d.ts` binding source of truth).
