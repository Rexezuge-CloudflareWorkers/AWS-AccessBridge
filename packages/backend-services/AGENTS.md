# AWS-AccessBridge — Backend Services (Business Logic)

Scope: `packages/backend-services/**`. Parent index: `../../AGENTS.md`. Feature details: `../../docs/agents/features/*/AGENTS.md`.

Instance services by domain (constructor-injected narrow `*Env`; resolve per-request via `scope.get(Tokens.X)` from `composition/` — the DI composition root — or legacy `*Factory.create(env)` during migration): `credential/` (`CredentialService` facade over `CredentialChainService` chain resolution incl. cache-short-circuit + `CredentialStoreService` store/relationship CRUD + STS validate; `CredentialChainWalker` Template Method with `LeafCredentialsWalker`/`ChainTestWalker`), `aws/assume-role/` (`AssumeRoleService` — access check → chain → cached-hop reuse → chain walk), `aws/console/` (`ConsoleService` — signin tokens, login/issuer/destination URL builders), `aws/sts|iam|ce/` (thin domain delegates over raw `provider-clients` `StsClient`/`IamClient`/`CostExplorerClient`), `aws/collectors/` (`IAwsResourceCollector` Strategy + `BaseAwsCollector` Template base + `CollectorRegistry` statics + `InjectableCollectorRegistry.withDefaults/withOverrides` seam: `Ec2/S3/Lambda/Rds/DynamoDbCollector`), `auth/` (`AccessAuthService` — Access JWT/demo/dev; `TokenService` — PAT auth + token CRUD), `account/` (`AccountService` — nicknames, role configs, role discovery), `access/` (`AccessService` — grant/revoke), `user/` (`UserService` — profile, favorites, hidden roles, assumables; preferred-language writes/reads normalized via shared `LocaleUtil`), `cost/` (`CostService` — summary/account/trends, alerts, collection config), `resource/` (`ResourceService` — search/summary), `team/` (`TeamService`), `maintenance/` (`MaintenanceService` — orphan cleanup, task runs), `audit/` (`AuditService` fan-out via `AuditObserverRegistry` + `AuditPayloadBuilder` request→event mapping + `AuditEventBuilder` + `AuditLogObserver`; `AUDIT_ACTIONS` map), `http/` (`IHttpClient` → `FetchHttpClient`/`StubHttpClient` with `queueJson/queueError/setHandler/calls` + `fetchJson` + `HttpFetchError`/`isRetryableHttpStatus`; `AwsClient*` types re-exported from `provider-clients`), `composition/` (`Tokens` + `createRequestScope` + `createService`).

Pure static utilities stay static (Otter precedent): `aws/ArnUtil`, `aws/BaseUrlUtil`, `aws/InternalRequestHelper` (instance, holds fetcher+secret), `error/` (`ErrorTranslationUtil`, `ErrorDeserializationUtil`).

Related packages: `shared/` (constants incl. canonical `StsMessages`/`HmacMessages`, models, schemas, utils `TimestampUtil`, `UUIDUtil`, `RequestOriginUtil`, `EmailUtil`, `LocaleUtil`; `i18n/` with `BackendStrings` + `formatBackendString`, `getBackendStrings`), `backend-errors/` (`BadRequestError`, `UnauthorizedError`, `ForbiddenError`, `MethodNotAllowedError`, `InternalServerError`, `DatabaseError` (+`retryable`), `IServiceError`, message constants; compat copies of STS/HMAC strings), `backend-runtime/` (env `ConfigurationDefaults`, `ConfigurationManager` namespaced getters + `EnvParser`, `Configurations`; `di/` `Container` + `ServiceContext`; abstract worker bases `AbstractEntrypointWorker`, `AbstractDurableObjectWorker`; DO naming constants; checked-in `env.d.ts` binding source of truth), `provider-clients/` (raw AWS: `AwsSignedFetcher` + `StsClient`/`CostExplorerClient`/`IamClient`).
