# AWS-AccessBridge — Backend Services (Business Logic)

Scope: `packages/backend-services/**`. Parent index: `../../AGENTS.md`. Feature details: `../../docs/agents/features/*/AGENTS.md`.

Instance services by domain (constructor-injected `ServiceEnv`; resolve per-request via `getRequestScope(env).get(Tokens.X)` from `composition/` — the DI composition root, and the only supported way to construct a service): `identity/` (`UserIdentityService` — address → account resolution: `user_emails` registry first (only `is_verified = 1` may authenticate, so a revoked address never resolves), then `user_metadata.current_email`, then the frozen anchor as the pre-0032 floor; memoized per request scope; `resolveAccount`/`resolveUserId`/`resolveAccountById`/`listAddresses`/`setPrimaryEmail`/`linkVerifiedEmail`, plus `idOf(account)` — the one place an empty id becomes `null` for a `user_id` write, since binding `''` fails the 0032 foreign keys), `credential/` (`CredentialService` facade over `CredentialChainService` chain resolution incl. cache-short-circuit + `CredentialStoreService` store/relationship CRUD + STS validate; `CredentialChainWalker` Template Method with `LeafCredentialsWalker`/`ChainTestWalker`), `aws/assume-role/` (`AssumeRoleService` — access check → chain → cached-hop reuse → chain walk), `aws/console/` (`ConsoleService` — signin tokens, login/issuer/destination URL builders), `aws/sts|iam|ce/` (thin domain delegates over raw `provider-clients` `StsClient`/`IamClient`/`CostExplorerClient`), `aws/collectors/` (`IAwsResourceCollector` Strategy + `BaseAwsCollector` Template base — owns the fetch/`!ok`→`[]` error isolation via `fetchText`/`fetchJson`, which all 5 collectors use — + `CollectorRegistry` statics + `InjectableCollectorRegistry.withDefaults/withOverrides` seam: `Ec2/S3/Lambda/Rds/DynamoDbCollector`), `auth/` (`AccessAuthService` — Access JWT/demo/dev; `TokenService` — PAT auth + token CRUD; `authenticateWithPAT` resolves the owner's CURRENT address from the token's `user_id` rather than the stored anchor, so a token minted before an address change does not authenticate as the old address forever — and quota/ownership are id-keyed with an address fallback), `account/` (`AccountService` — nicknames, role configs, role discovery), `access/` (`AccessService` — grant/revoke), `user/` (`UserService` — profile, favorites, hidden roles, assumables; preferred-language writes/reads normalized via shared `LocaleUtil`). Services taking the caller still take their sign-in ADDRESS and resolve the account internally (`this.identity.resolveAccount`) rather than accepting an id — the authenticated principal at the edge is always an address, so the id is a read-path implementation detail and the route/OpenAPI/web surface stays unchanged. Every write provisions and writes against the resolved **anchor**, never the presented address; `AssumeRoleService`'s `userId` local is the STS `RoleSessionName` (from `federation_username`), NOT the account id, `user/` (`UserService` — profile, favorites, hidden roles, assumables; preferred-language writes/reads normalized via shared `LocaleUtil`), `cost/` (`CostService` — summary/account/trends, alerts, collection config), `resource/` (`ResourceService` — search/summary), `team/` (`TeamService`), `maintenance/` (`MaintenanceService` — orphan cleanup, task runs), `audit/` (`AuditService` fan-out via `AuditObserverRegistry` + `AuditPayloadBuilder` request→event mapping + `AuditEventBuilder` + `AuditLogObserver`; `AUDIT_ACTIONS` map), `composition/` (`ServiceEnv` — the single source of truth for what a service may read; `Tokens` (incl. `UserIdentityService`, bound once per request scope so the address→account memo is a per-request cache); `createRequestScope`; `getRequestScope` — a `WeakMap` keyed on `env` giving one scope, and one `AES_ENCRYPTION_KEY_SECRET.get()`, per request); `http/` (`IHttpClient` → `FetchHttpClient`/`StubHttpClient` with `queueJson/queueError/setHandler/calls` + `fetchJson` + `HttpFetchError`/`isRetryableHttpStatus`; `AwsClient*` types re-exported from `provider-clients`), `composition/` (`ServiceEnv` — the single source of truth for what a service may read; `Tokens`; `createRequestScope`; `getRequestScope` — a `WeakMap` keyed on `env` giving one scope, and one `AES_ENCRYPTION_KEY_SECRET.get()`, per request).

Pure static utilities stay static (Otter precedent): `aws/ArnUtil`, `aws/BaseUrlUtil`, `aws/InternalRequestHelper` (instance, holds fetcher+secret), `error/` (`ErrorTranslationUtil`, `ErrorDeserializationUtil`).

Related packages: `shared/` (constants incl. canonical `StsMessages`/`HmacMessages`, models, schemas, utils `TimestampUtil`, `UUIDUtil`, `RequestOriginUtil`, `EmailUtil`, `LocaleUtil`, `RegexUtil.matchAll`; `i18n/` with `BackendStrings` + `formatBackendString`, `getBackendStrings`), `backend-errors/` (`BadRequestError`, `UnauthorizedError`, `ForbiddenError`, `MethodNotAllowedError`, `InternalServerError`, `DatabaseError` (+`retryable`), `IServiceError`), `backend-runtime/` (env `ConfigurationDefaults`, `ConfigurationManager` namespaced getters + `EnvParser` — all tunables are `DEFAULT_*` _string_ constants parsed on read, and an unparseable value falls back to the default rather than throwing; `di/` `Container`; abstract worker bases `AbstractEntrypointWorker`, `AbstractDurableObjectWorker`; `SCHEDULED_TRIGGER_PATH`; DO naming constants; checked-in `env.d.ts` binding source of truth), `provider-clients/` (raw AWS: `AwsSignedFetcher` + `StsClient`/`CostExplorerClient`/`IamClient`).
