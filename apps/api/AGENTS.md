# AWS-AccessBridge — API Worker

Scope: `apps/api/**`. Parent index: `../../AGENTS.md`.

- `src/index.ts` — exports `fetch`/`scheduled` via `AccessBridgeWorker`; re-exports `CronTasksWorker` from `@aws-access-bridge/background` for the DO binding.
- `src/types.d.ts` — references the generated `worker-configuration.d.ts` + the checked-in `packages/backend-runtime/src/env.d.ts` (binding source of truth).
- `src/workers/AccessBridgeWorker.ts` — Hono + Chanfana app, `hmacValidation` global, `userAuthentication`/`apiAuthentication`, `fromHono` openapi `/docs`, `registerUserRoutes` (delegates to domain helpers `registerAws/UserAccount/AdminAccount/Cost/Resource/Team/MaintenanceRoutes`) + `registerApiRoutes`, SPA catch-all (`ConfigurationManager.spa`), `onScheduled` → `CRON_TASKS` DO.
- `src/endpoints/` — one thin class per route (`user/…`, `api/…`, `IActivityAPIRoute.ts` (`handle` → `handleRequest` Template Method + `toResponse`/`toErrorResponse`/`getQueryParam` helpers; session/demo/base-URL concerns extracted to `route-helpers.ts`), `IAdminActivityAPIRoute.ts` (demo-mode + super-admin guard), `index.ts` (direct typed re-exports)). Routes resolve domain services via `getRequestScope(env).get(Tokens.X)` from `backend-services/composition` (never `new XService(env)`) and never import DAOs (ESLint `no-restricted-imports`, type-only imports excepted). `toErrorResponse` returns typed messages for 4xx only — a 5xx (including `DatabaseError`, whose message embeds raw D1/SQLite text) is logged and answered with the generic `DefaultInternalServerError`.
- `src/middleware/` — `HMACHandler.ts` (internal HMAC verify), `MiddlewareHandlers.ts` (module-scope handlers + thin static factories).
- `src/schema/` — thin re-export layer over `@aws-access-bridge/shared/schema`.
- `src/generated/spa-shell.ts` — generated by the web build; do not edit.

## Auth

- `/user/*` — Cloudflare Access. `AccessAuthService.getAuthenticatedUserEmail` resolves in order: `DEMO_MODE` → `DEV_AUTH_EMAIL` (local-only) → JWT verification via `jose` against `{TEAM_DOMAIN}/cdn-cgi/access/certs` with audience `POLICY_AUD` (reads the `cf-access-jwt-assertion` header, extracts `payload.email`) → platform-verified `ctx.access.getIdentity()` fallback when `TEAM_DOMAIN`/`POLICY_AUD` are unset (Worker-level Access, same-account one-click deploys). Explicit vars always win over the fallback when set. Never trust the spoofable `Cf-Access-Authenticated-User-Email` request header (locked by tests).
- `DEV_AUTH_EMAIL` (no default, local-only) bypasses Access and returns directly, logging a warning — **unless** `ConfigurationManager.environment.isProduction(env)`, where it throws `InternalServerError` instead. It is read before JWT verification from an ordinary var, so without that guard a `.dev.vars` promoted by mistake authenticates every caller as that address, super-admin included. `ENVIRONMENT` defaults to `development`; only the literal `production` arms the guard, so the integration suite (which sets `DEV_AUTH_EMAIL` in vars) keeps working. `DEMO_MODE=true` bypasses with `demo@example.com` and takes precedence.
- `/api/*` — Bearer PAT (`TokenService.authenticateWithPAT`) or HMAC-signed internal self-calls (`X-Internal-*` + `X-Internal-User-Email` after `hmacValidation()`). `authenticateWithPAT` takes an optional `defer` callback: the `last_used_at` stamp is a D1 write that `updateLastUsedByToken` throws on, so the middleware passes `ctx.waitUntil` rather than awaiting it on the auth path (a write-side blip must not turn a valid PAT into a 500).
- Request/response auditing via `AuditService` (Observer fan-out) in `activityAudit()`. The event carries the account id alongside the address (best-effort; absent on a database without migration 0032) so an entry stays findable after an address change. `AuditObserverRegistry.notifyAll` fans out with `allSettled` and logs each rejection itself — it does not return the settled results, because `record` discarded them and a failed `AuditLogDAO.create` vanished with no trace.
- Identity: `AuthenticatedUserEmailAddress` is the address the request authenticated as; `AuthenticatedUserId` is the stable account key it resolves to (`MiddlewareHandlers.publishAccountId`, best-effort — a failure logs and continues, because the address alone is still a complete identity). Both are read through `IActivityAPIRoute.getAuthenticatedUserEmailAddress` / `getAuthenticatedUserId`; routes and the OpenAPI surface stay address-based by design, since services resolve the account internally.
- Never import `aws4fetch` in `apps/api` (ESLint-enforced) — route AWS SDK usage through `@aws-access-bridge/backend-services`. Never import `@aws-access-bridge/provider-clients` in `apps/api` either (same rule) — same path.
- `/docs`, `/openapi.json` — Chanfana generated (`fromHono`), public.

## Routes

Protected (`/user/*`, registered in `AccessBridgeWorker.registerUserRoutes`):
`POST /user/aws/console` · `POST /user/aws/assume-role` · `GET /user/aws/federate` · `GET /user/me` · `PUT /user/me` · `GET /user/assumables` · `GET /user/assumables/search` · `POST|DELETE /user/assumable/hidden` · `POST|DELETE /user/favorites` · `GET|POST|DELETE /user/tokens` · `GET /user/costs/summary` · `GET /user/costs/account` · `GET /user/costs/trends` · `GET /user/resources` · `GET /user/resources/summary` · admin credentials (`POST /user/admin/credentials`, `POST|DELETE …/relationship`, `POST …/validate`, `POST …/test-chain`), access (`POST|DELETE /user/admin/access`), account nickname (`PUT|DELETE`), account roles (`POST`), role config (`PUT|DELETE`), `GET /user/admin/audit-logs`, costs alerts (`POST|DELETE`), collection config (`POST|DELETE`), teams (CRUD + members + accounts), maintenance (`POST …/cleanup-orphaned`, `GET …/task-runs`)

Programmatic (`/api/*`): `POST /api/aws/assume-role` · `POST /api/aws/console` · `GET /api/aws/federate` (same classes as the `/user/aws/*` trio)

Catch-all: only `/user/` page paths serve `SPA_HTML` (pages namespaced under `/user/app/*` so they never collide with `/user/*` JSON API routes like `GET /user/resources`); everything else returns 404 so `/api/*` is never intercepted. `/` redirects to `/user/` (canonical entry — top-level navigation here triggers the Zero Trust login); `/user` normalizes to `/user/`; legacy `/costs`, `/resources`, `/admin/*` redirect to `/user/app/*`.
